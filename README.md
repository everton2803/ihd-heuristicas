## 🎯 Objetivo do projeto

Este projeto tem como objetivo desenvolver uma plataforma web para:

- Registrar faltas de alunos
- Inserir justificativas
- Visualizar registros
- Gerar relatórios
- Aplicar heurísticas de usabilidade

## 🧠 Heurísticas de Nielsen

O sistema foi desenvolvido com base nas 10 heurísticas:

1. Visibilidade do status do sistema
2. Mundo real
3. Controle do usuário
4. Consistência
5. Prevenção de erros
6. Reconhecimento
7. Eficiência
8. Design minimalista
9. Recuperação de erros
10. Ajuda
