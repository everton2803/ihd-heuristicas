## 🎯 Objetivo do projeto

Este projeto tem como objetivo o desenvolvimento de uma **plataforma web para gestão de faltas de alunos**, com foco em:

- Registro de presença/ausência por turma e data
- Inserção de justificativas
- Visualização de informações organizadas
- Geração de relatórios
- Exportação de dados

Além disso, o sistema foi desenvolvido com base em princípios de **Interação Humano-Computador (IHC)**, aplicando as **Heurísticas de Usabilidade de Jakob Nielsen**.

---

## 🧠 Fundamentação teórica

As **10 Heurísticas de Nielsen** foram utilizadas como base para:

- Planejamento da interface
- Organização dos elementos visuais
- Melhoria da experiência do usuário
- Avaliação da usabilidade do sistema

A aplicação dessas heurísticas permitiu identificar:

✅ Pontos fortes da interface  
❌ Problemas de usabilidade  
🔧 Oportunidades de melhoria

## 🖥️ Funcionalidades do sistema

### ✔ Registro de faltas
- Seleção de turma
- Seleção de data
- Marcação de alunos ausentes
- Inserção de justificativa (opcional)

### ✔ Persistência de dados
- Utilização de **LocalStorage**
- Dados armazenados no navegador

### ✔ Relatórios
- Filtro por período
- Resumo por aluno
- Indicadores de faltas

### ✔ Exportação
- Formato CSV
- Formato JSON
